# Spot the Error: Pharmacy Visual Verification

GitHub Pages-ready static training game with 20 fictional pharmacy verification cases.

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload all contents of this folder, preserving the `assets/cases` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

Open `index.html` locally to preview. No server or build tools are required.
